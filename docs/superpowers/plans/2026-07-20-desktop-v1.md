# PyWatermarkCleaner Desktop v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:test-driven-development for production behavior. Every task ends with focused tests and a deliberate commit.

**Goal:** Deliver the approved cross-platform desktop v1 while preserving CLI invocation compatibility.

**Architecture:** An installable `src` package separates immutable processing services from PySide6 widgets and controllers. OpenCV decodes and inpaints frames; the FFmpeg executable supplied by `imageio-ffmpeg` encodes safe outputs and maps optional audio.

**Tech stack:** Python 3.12-3.14, NumPy, OpenCV, PySide6 Qt Widgets, imageio-ffmpeg, pytest/pytest-qt, Ruff, mypy, PyInstaller.

## Global constraints

- Branch: `feature/desktop-v1`; never implement on `main`.
- Inputs are never overwritten; partial outputs are cleaned on failure/cancel.
- Core modules do not import PySide6.
- Preview long edge is at most 1280 px; export is full resolution.
- Default method/radius/workers: Telea, 3, 1; GUI worker range is 1..`min(4, logical CPUs)`.
- Preserve existing CLI flags; unchanged invocations use the new safe output behavior.
- All new production behavior follows a demonstrated red-green test cycle.
